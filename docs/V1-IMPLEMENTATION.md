# 乐也教学管理系统 V1.0 实施基线

## 已确认的产品规则
- 家长端只读查看课表、成长记录、课时权益和通知；不提供自主预约、线上购买、在线支付、线上请假或补课预约。
- 负责人统一使用管理端操作；教师账号作为后续扩展。
- 家庭、监护人、学员必须建立显式授权关系；禁止仅凭姓名或手机号访问孩子数据。
- 课程商品快照进入订单；线下收款允许分次登记；默认全款开通课时，提前开通必须由负责人授权并记录原因。
- 每个订单最多一笔退款；退款线下处理；退款金额不可超过允许退款上限。
- 课时余额必须由不可变流水汇总；赠送课时优先消耗；未确认实际授课不得消课。
- 调课保留原课次及历史；检查教师、教室、学员冲突。
- AI 第一版仅预留接口；家长可见教学内容须经负责人/教师审核。
- 工作室时区为 America/Chicago；数据库时间统一 UTC。

## 数据迁移
旧版 courses 与 bookings 表保留。新业务结构通过编号 SQL migration 增量创建，禁止在升级时清空或重建旧表。

## 交付阶段
1. 数据模型与迁移框架、课时流水规则。
2. 管理后台身份认证、家庭/学员/课程/资源管理 API。
3. 排课、课次、冲突检查、考勤及消课。
4. 订单、分次收款、权益开通和一次性退款。
5. 家长端身份绑定、课表、成长、课时和通知。
6. 端到端测试、备份恢复与部署手册。

## 上线前置事项
真实微信登录与手机号验证、HTTPS 与小程序合法域名、隐私告知与授权、生产管理员认证、备份恢复演练和微信审核均需完成后方可正式发布。
